# fuaran

This distribution is a **placeholder**. It exports nothing and never will.

The Fuaran UI wire-format host for Python is published as **`fuaran-ui`**:

```sh
pip install fuaran-ui
```

```python
from fuaran_ui.ui import fuaran, encode
```

Repository: <https://github.com/fuaran-ui/fuaran-py>. Documentation:
<https://fuaran-ui.io/get-started/python>.

The bare name is held so that `fuaran` cannot be taken by an unrelated project and
mistaken for that host — the same posture the unscoped npm name `fuaran` and the
bare `fuaran` crate take beside `@fuaran-ui/*` and `fuaran-ui`. `fuaran` is the
family name, not a host: the UI domain's Python host is `fuaran-ui`, and a future
Fuaran domain with a Python host would name its own domain the same way.
